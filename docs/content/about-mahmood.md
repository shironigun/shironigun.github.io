## How he works

### Operating model

- **Discover:** Frame the right problem with the people who have it.
- **Define:** Write requirements that can be tested before anyone builds.
- **Design:** Review every design before development starts.
- **Prototype:** Let people use the idea before we commit to building it.
- **Deliver:** Keep the sprint predictable and the risks visible.
- **Release:** Ship only what meets the agreed criteria.

### Principles

- **Settle edge cases before the build** (68% of leaked defects traced to incomplete acceptance criteria, before Quality Gates)
- **Review the design before development** (7 product areas revamped through the design phase)
- **Make knowledge reusable** (60+ SOPs and guides written for every team)
- **Test AI output like any software** (4 rules set to rebuild an AI-built test suite after auditing it)
- **Keep a person in control** (29 AI skills that ask before they write)
- **Standardise what works** (5+ teams adopted the API testing approach I evaluated)

### AI ground rules

- **I decide; agents build:** I own the problem, the requirements, the architecture trade-offs and what ships. AI agents write the code from my specifications.
- **AI output is tested like software:** Everything an agent produces is reviewed and tested. My own audit found tests in an AI-built suite that passed with the backend switched off.
- **Every write needs a yes:** The tools I build show a dry run first and wait for explicit approval before writing to a team’s tracker.
- **Results come from real runs:** A result counts only when a real run produced it, never because an agent reported success.
- **Clear ownership:** Every project separates what I decided, what AI built and what the team delivered.

### Skills and AI behaviour he has written

- **Test-case drafting skill:** Drafts test cases in my house style, learned from hundreds of test cases I had written.
- **QA Engineering Plugin:** 30 skills across seven plugins, from story analysis to filed bugs.
- **AI feature behaviour:** The rules an AI feature follows: what it detects, when it acts and what it must never say.
